# 01. 요구사항

## 첫 버전의 범위

### 필수 기능

- [ ] 세 과목과 전체 강의 수(297강)를 표시한다.
- [ ] 날짜별 계획 강의와 OX 복습 항목을 표시한다.
- [ ] 강의별 완료 체크와 오늘 과제 전체 완료·초기화를 제공한다.
- [ ] 오늘의 달성률을 표시한다.
- [ ] 과목별 완료 강의 수와 진도율을 표시한다.
- [ ] 전체 완료 강의 수, 남은 강의 수, 전체 진도율을 표시한다.
- [ ] 완강 목표일(2027년 1월 15일)까지 남은 날짜를 표시한다.
- [ ] 학습 캘린더에서 공부일, 휴식일, 완료 상태를 확인한다.
- [ ] 체크 상태를 저장하고 다시 방문했을 때 복원한다.
- [ ] MacBook, iPhone, iPad 화면에 맞춰 사용할 수 있게 한다.
- [ ] 날짜 표시와 날짜 계산은 `Asia/Seoul` 기준으로 처리한다.

### 초기 학습 데이터

| 과목 | 시작 강의 | 마지막 강의 | 개수 |
|---|---:|---:|---:|
| 행정법총론 | 2 | 86 | 85 |
| 소방관계법규 | 1 | 104 | 104 |
| 소방학개론 | 1 | 107 | 107 |

초기 계획 기간: 2026-11-20 ~ 2027-01-15. 날짜별 강의 배정은 기존 `index.html` 시제품의 계획을 기준으로 옮긴다.

### 이번 첫 버전에서 미루는 기능

- [ ] 계정 로그인과 기기 간 자동 동기화
- [ ] 미완료 강의를 남은 날짜에 맞춰 자동 재배치
- [ ] 오답 노트 및 상세 복습 기록
- [ ] 여러 사용자의 계획 관리

이 기능들은 배포 가능한 기본 버전이 완성된 뒤 우선순위를 정한다. 특히 여러 기기 간 동기화에는 서버 저장소와 인증 방식이 필요하므로 별도 설계한다.

## 완료 기준

- [ ] 한국 시간 기준 날짜가 정확하며, 달력 날짜가 하루씩 밀리지 않는다.
- [ ] 계획이 없는 날에는 이전 날짜의 강의가 오늘 과제로 표시되지 않는다.
- [ ] 강의 완료 체크에 따라 과목별·전체 진도율이 갱신된다.
- [ ] OX 완료 상태가 강의 완료 수에 잘못 포함되지 않는다.
- [ ] 저장한 상태가 같은 브라우저에서 새로고침 후 유지된다.
- [ ] 모바일에서도 체크와 주요 정보 확인이 가능하다.
- [ ] GitHub 저장소와 연결되고 Vercel 배포 URL에서 앱을 이용할 수 있다.
