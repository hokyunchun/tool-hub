# 01. 요구사항

## 첫 버전의 범위

### 필수 기능

- [ ] 세 과목과 전체 강의 수(297강)를 표시한다.
- [ ] 날짜별 계획 강의와 OX 복습 항목을 표시한다.
- [ ] 강의별 완료 체크와 오늘 과제 전체 완료·초기화를 제공한다.
- [ ] 오늘의 달성률을 표시한다.
- [ ] 과목별 완료 강의 수와 진도율을 표시한다.
- [ ] 전체 완료 강의 수, 남은 강의 수, 전체 진도율을 표시한다.
- [ ] 완강 목표일(2027년 1월 15일)까지 남은 날짜를 표시한다.
- [ ] 학습 캘린더에서 공부일, 휴식일, 완료 상태를 확인한다.
- [ ] 체크 상태를 저장하고 다시 방문했을 때 복원한다.
- [ ] MacBook, iPhone, iPad 화면에 맞춰 사용할 수 있게 한다.
- [ ] 날짜 표시와 날짜 계산은 `Asia/Seoul` 기준으로 처리한다.

### 초기 학습 데이터

| 과목 | 시작 강의 | 마지막 강의 | 개수 |
|---|---:|---:|---:|
| 행정법총론 | 2 | 86 | 85 |
| 소방관계법규 | 1 | 104 | 104 |
| 소방학개론 | 1 | 107 | 107 |

초기 계획 기간: 2026-11-20 ~ 2027-01-15. 날짜별 강의 배정은 기존 `index.html` 시제품의 계획을 기준으로 옮긴다.

### 계정/확장 버전

- 이메일 계정별로 학습 계획과 완료 기록을 분리한다.
- 체크 기록은 Supabase에 저장하고 Realtime으로 다른 로그인 기기에 반영한다.
- 새 사용자는 과목명, 강의 수, 시작일, 목표일을 입력해 자신의 계획을 만든다.
- 일정은 시작일과 목표일 사이 평일에 과목별 강의를 균등 배정한다.
- 대시보드는 과목 진도, 전체 진도, 남은 강의, D-Day, 캘린더를 유지한다.
- 과목별 평균 강의 시간을 설정하고 선택일의 예상 강의 시수를 보여준다.
- 제공된 수강 기록의 평균 재생시간을 기존 소방 계획에 기본값으로 적용한다: 행정법총론 72분(86개), 소방관계법규 47분(103개), 소방학개론 49분(106개). 누락 2개는 평균에서 제외한다.
- 기존 사용자에게는 현재 297강 일정과 브라우저에 남은 체크 기록을 가져오는 선택지를 제공한다.
- 캘린더 과목 색상: 행정법총론 연한 파랑, 소방관계법규 연한 빨강, 소방학개론 연한 노랑.

### 아직 미루는 기능

- [ ] 미완료 강의를 남은 날짜에 맞춰 자동 재배치
- [ ] 오답 노트 및 상세 복습 기록
- [ ] 한 사용자 계정에서 여러 계획을 전환/관리
- [ ] 개별 강의 실제 길이를 강의별로 저장 (현재는 제공된 강의 시간의 과목별 평균으로 계산)

클라우드 저장을 활성화하려면 Supabase 프로젝트 설정과 SQL 적용이 필요하다.
docs/apps/fire-study-planner/supabase-setup.sql을 실행한 뒤 Vercel에 SUPABASE_URL,
SUPABASE_ANON_KEY 환경 변수를 설정한다.

## 완료 기준

- [ ] 한국 시간 기준 날짜가 정확하며, 달력 날짜가 하루씩 밀리지 않는다.
- [ ] 계획이 없는 날에는 이전 날짜의 강의가 오늘 과제로 표시되지 않는다.
- [ ] 강의 완료 체크에 따라 과목별·전체 진도율이 갱신된다.
- [ ] OX 완료 상태가 강의 완료 수에 잘못 포함되지 않는다.
- [ ] 저장한 상태가 같은 브라우저에서 새로고침 후 유지된다.
- [ ] 모바일에서도 체크와 주요 정보 확인이 가능하다.
- [ ] GitHub 저장소와 연결되고 Vercel 배포 URL에서 앱을 이용할 수 있다.
