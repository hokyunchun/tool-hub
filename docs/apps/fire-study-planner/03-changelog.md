# 03. 변경 기록

## 2026-11-19 — 기획 초안

- 소방시험 Study Planner를 첫 장기 미니 프로젝트로 정했다.
- 기존 시제품의 강의 수와 날짜별 계획을 초기 요구사항에 반영했다.
- 문서 구조를 `00-idea`, `01-requirements`, `02-design`, `03-changelog`로 정리했다.
- 한국 시간대 `Asia/Seoul`을 날짜 기준으로 명시했다.
- 첫 버전의 목표를 GitHub 관리와 Vercel 배포까지로 정했다.

## 2026-11-19 — Tool Hub 통합

- 단독 Vercel 주소 대신 Tool Hub의 `/tools/fire-study-planner` 경로로 제공하도록 통합했다.
- Tool Hub 홈의 도구 목록에 Study Planner 카드를 추가했다.
- 브라우저 날짜와 진도 저장은 한국 시간 및 브라우저 저장 방식을 유지한다.

## 2026-11-19 — 사용자별 계획, 저장, 표시 개선

- Supabase 이메일 계정, 사용자별 계획 데이터, 진도 기록 저장과 Realtime 동기화를 추가했다.
- 사용자가 과목별 강의 수와 목표일을 입력해 평일 계획을 만드는 시작 화면을 추가했다.
- 기존 브라우저의 297강 완료 기록을 새 계정의 기존 일정으로 가져오는 경로를 추가했다.
- 캘린더의 세 과목을 연한 파랑·연한 빨강·연한 노랑으로 구분하고 완료 상태는 초록 테두리로 표시한다.
- 선택 날짜의 강의 수에 과목별 평균 강의 시간을 곱해 예상 학습 시간을 표시한다.
- 기존 강의 데이터에 강의별 영상 길이는 포함되어 있지 않아, 초기 예상 시간은 1강당 60분으로 설정했다. 새 계획에서는 사용자가 과목별 분당 시간을 입력할 수 있다.
- Supabase 연결에 필요한 SQL은 supabase-setup.sql에 기록했다. Vercel 환경 변수가 설정되기 전에는 로컬 저장 모드로 동작한다.
